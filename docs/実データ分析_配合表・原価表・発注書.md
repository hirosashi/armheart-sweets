## 1. いちばん大きな発見：配合は「1台あたり」ではなく「バッチ（仕込み単位）」で書かれている

配合表の作りは次のようになっています。

```
商品（クロミ クリスマスチョコケーキ／4号ホール）
├─ 部位「4号茶スポンジ」   充填量 150g/台   ← 1台に使う量
│   └─ バイオレット240g／上白糖ES280g／PP凍結全卵400g … 合計 1,144g  ← 1バッチの仕込み量
├─ 部位「φ7cm茶スポンジ」 充填量 2,000g     バッチ合計 2,860g
├─ 部位「グラサージュ」     充填量 85g/台    バッチ合計 761.6g
├─ 部位「チョコレートムース」充填量 160g/台   バッチ合計 1,848g
├─ 部位「トッピング」       充填量 6g/台（クリスパール ダーク）
├─ 部位「クロミ顔チョコ」   1枚/台（枚数で数えるもの）
└─ 部位「滑り止め」         充填量 3g/台（ナパージュヌートル）
```

つまり必要量は2段階の計算になります。

```
ある材料の必要量 =
  台数 × その部位の充填量(g/台) ÷ その部位のバッチ合計(g) × その材料のバッチ配合量(g)
```

例：500台つくる場合の「4号茶スポンジ」のバイオレット
`500台 × 150g ÷ 1,144g × 240g ＝ 15,734g`

**現在のテーブル設計は「1パーツあたりの材料量」しか持っていないため、この計算ができません。**
下の 4章のとおりテーブルを直します（今の段階なら影響は小さいので、画面を作る前に直します）。

さらに現場の実態として、次の情報も配合表に書かれています。

- 取り数：「1.5cm厚 2枚取り 1枚使用」「φ7 1スライス28個取り／合計56個取り/台」
- 歩留まり：原価計算表に `歩留まり(/0.9)` → **ロス率10%** を見込んで計算している
- 「水」は材料に含まれるが単価0（在庫管理の対象外）
- 「クロミフェイス／クロミドクロ」は **1枚/台** のように g ではなく枚で数える

## 2. 原材料マスタ（実在するデータ）

| 項目 | 中身 |
|---|---|
| 件数 | 約490件（原価計算表のマスタ）／配合表のマスタは168件 |
| 持っている情報 | 原材料名・メーカー名・**kg単価**・**アレルギー**・単価の根拠（例「2026.05.25納品書」） |
| 注意点1 | 同じ材料に複数表記がある（例「未殺菌液全卵(ロカ)／液全卵ロカ(未殺菌)／未殺菌液卵(全卵)」）。メーカーも「サンヨーエッグ／E&TAMAGO／青木養鶏所／伊藤鶏卵」と併記 → **代替可能な材料**の考え方が必要 |
| 注意点2 | 同じ材料でも会社（アルムハート／エスワイプラス）で単価が違う |
| 注意点3 | 単価は「いつの納品書の値か」が管理されている → 単価に適用日を持たせる価値あり |
| アレルゲン | 小麦・卵・乳成分・大豆・ゼラチン・アーモンド等。商品ヘッダの「含有アレルゲン」は材料から積み上げられる |

「スポンジマスタ」は、共通で使うスポンジ配合（プレーン／ココア／ブラックココア）と、
号数ごとの充填量（4号150g・5号220g・6号300g・7号460g・8号580g・9号670g …）を持つ表です。
→ **共通パーツ＋号数ごとの充填量**という形でそのままシステムに入れられます。

## 3. 発注書のフォーマット（実物どおりに作れます）

```
                       発　注　書                        2026/07/08（発注日）
株式会社ホーライ御中
                                     発注者： 株式会社アルムハート
                                     住所：   栃木県下都賀郡壬生町大字安塚3343-11

下記の通り、発注いたします。
希望納期： 2025/12/25
納品場所： 株式会社アルムハート
─────────────────────────────────
 商品名                        規格   数量  単位   備考
 お餅シートプレーンS-5.5-5.5           1   ケース
─────────────────────────────────

```

読み取ったポイント

- **金額欄がない**（数量と単位だけ）。現行設計は単価・金額を持っているので、発注書には出さない設定にします
- 発注元（自社）が2社ある：**株式会社アルムハート**（壬生町）と **株式会社エスワイプラス**（宇都宮）
- 「希望納期」「納品場所」が必須項目
- 単位は「ケース」など仕入単位。1シート＝1回の発注で、日付ごとにシートを複製して使っている

## 4. テーブル設計の修正案（画面を作る前に反映したい）

| テーブル | 追加・変更する項目 | 理由 |
|---|---|---|
| `parts`（部位） | `batch_total_qty`（バッチ合計量）、`batch_unit`、`yield_rate`（歩留まり 既定0.9）、`is_common`（共通パーツか） | バッチ配合から1台あたりへ換算するため |
| `product_parts` | `fill_qty`（充填量 g/台）、`fill_unit`（g／枚）、`pieces_per_batch`（取り数）、`note`（「2枚取り1枚使用」等） | 1台に使う量は充填量で決まる |
| `part_materials` | `qty` は「バッチ配合量」と定義を明確化、`display_order` | 配合表の並び順を保つ |
| `materials` | `maker_name`（メーカー）、`allergens`（アレルゲン）、`price_per_kg`、`price_source`（例「2026.05.25納品書」）、`price_date`、`category`（原材料／生産用資材／商品用資材）、`is_supplied`（支給品）、`alias_names`（別表記）、`is_stock_managed`（水などを除外） | 実データが持っている情報 |
| `products` | `seller_name`（販売者：伊藤忠食品）、`spec`（4号ホール）、`pieces_per_case`（入り数）、`shelf_life`、`thaw_shelf_life`（解凍後）、`launch_date`（導入予定）、`plan_qty_note`（限定数 3000〜8000台）、`allergens`、`author`、`revised_at` | 配合表ヘッダの項目 |
| `purchase_orders` | `desired_delivery_date`（希望納期）、`delivery_place`（納品場所）、`company_id`（発注元＝自社） | 発注書の必須項目 |
| `purchase_order_items` | `spec`（規格）、`unit`（ケース等）、`note`（備考）、金額は画面内部のみ | 実物の発注書に合わせる |
| 新規 `companies` | 自社情報（社名・住所・TEL/FAX・納品場所の既定値） | 発注書の発注元が2社ある |
| 新規 `material_prices`（任意） | 材料ID・単価・適用日・根拠 | 単価改定の履歴を残す場合 |

必要量計算のSQLも、上の2段階（充填量÷バッチ合計×配合量、さらに歩留まりで割る）に書き換えます。

## 5. 今回の見積範囲との線引き（重要）

いただいた原価計算表には **原価計算（配合量当り金額・1g当り単価・1個当たり単価・包材込み単価・歩留まり後原価・掛率25%）** が入っていますが、
これは今回のフェーズA（MVP）の見積範囲には**入っていません**。

- 今回作る範囲：レシピ（配合）登録／必要量計算／発注／在庫照会
- 材料の **kg単価はマスタに保持** しますので、原価計算画面は次フェーズで追加できます（今回のデータ設計はそれを見越した形にします）
- 包材（フィルム・グラシン・内箱・外箱・台紙・別添ピック・紙帯・底紙）は、**発注対象**として materials に入れます（原価計算はしません）

## 6. ご確認いただきたいこと

1. **必要量の計算式**は「台数 × 充填量 ÷ バッチ合計 × 配合量 ÷ 歩留まり」で合っていますか。歩留まりは全部位0.9でよいですか（部位ごとに変える場合は部位別に設定します）
2. **バッチの丸め**：スポンジは1バッチ単位でしか仕込めないと思いますが、必要量は「バッチ何本」と表示すべきですか（例：2.3バッチ→3バッチ）
3. **発注元の会社**は「アルムハート」「エスワイプラス」の2社を切り替える形でよいですか
4. **原材料マスタの取り込み**：約490件を原価計算表のマスタからそのまま初期データとして投入してよいですか（会社ごとに単価が違うため、まずはアルムハートの単価で登録する想定）
5. **材料の別表記**（未殺菌液全卵の4表記など）は、代表名1つ＋別名として扱ってよいですか
6. 「水」のように在庫管理しない材料は、必要量には出すが在庫・発注の対象外としてよいですか
7. **取り数の解釈**を教えてください。原価計算表の1個当たり単価は、4号茶スポンジが「2枚取り1枚使用」で半分（82.5円→41.25円）、φ7cm茶スポンジが「56個取り/台」で1/56（1,099.6円→19.64円）になっています。前者は納得できますが、後者は「1台に56個使う」のか「1スライスから56個取れて1台には1個」なのか、資料からは断定できませんでした
8. 商品の**販売者（伊藤忠食品など）**は業者マスタに入れますか（仕入先とは別に「販売先」として持つ形になります）
